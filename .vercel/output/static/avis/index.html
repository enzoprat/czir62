Transparence

Pourquoi vous ne verrez jamais de faux avis ici

Il est techniquement trivial d'afficher « 4,9/5 sur 187 avis » sur un site internet. Aucune vérification n'est faite par le navigateur, et la mention passe parfaitement inaperçue. C'est précisément pour cela qu'elle ne vaut rien.

Nous avons fait un choix opposé, inscrit dans le code de ce site : la note et les avis affichés proviennent exclusivement de notre fiche Google. Tant qu'un avis n'existe pas réellement, cette page ne l'invente pas — et le balisage de données structurées envoyé à Google n'annonce aucune note.

C'est aussi une question de risque : afficher une note agrégée sans avis correspondants expose à une pénalité manuelle de Google, en plus d'être une pratique commerciale trompeuse.
